# RoadSentinel AI
### Don't Wait for Roads to Fail.

**AI-Powered Predictive Road Failure, Safety & Repair Intelligence System**

RoadSentinel AI is an intelligent road monitoring and analysis platform designed to identify road damage, predict potential road failures, improve road safety, and help authorities prioritize road maintenance.

## 🚀 Project Overview

RoadSentinel AI aims to make road maintenance smarter through Artificial Intelligence, Machine Learning, and data-driven insights.

The platform provides a dashboard to monitor road conditions, identify risky road segments, analyze road damage, and support repair planning.

## ✨ Key Features

- Road Condition Monitoring
- AI-Based Road Damage Detection
- Predictive Road Failure Analysis
- Road Safety Intelligence
- Critical Road Segment Identification
- Repair Priority Management
- Road Analytics Dashboard
- Road Map and Risk Visualization
- Reports and Analysis

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Atharva-7779/RoadSentinel-AI.git
cd RoadSentinel-AI
```

### 2. Setup Backend

```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Start the Flask backend using the project's configured startup command.

### 3. Setup Frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL shown in the terminal.
